*[PPE]: Personal Protective Equipment
*[YOLO]: You Only Look Once, a real-time object detection model family
*[mAP]: mean Average Precision, the primary detection accuracy metric
*[IoU]: Intersection over Union, overlap between two bounding boxes
*[ByteTrack]: A multi-object tracker that associates detections across frames using high and low confidence boxes
*[ReID]: Re-Identification, appearance-based matching to recover lost tracks
*[BoT-SORT]: A tracker that adds an appearance/ReID model on top of motion-based association
*[ADR]: Architecture Decision Record
*[ADD]: Architecture Decision Detail, a numbered sub-decision inside one ADR
*[RTSP]: Real Time Streaming Protocol, common for IP/CCTV camera feeds
*[FPS]: Frames Per Second
*[VRAM]: Video RAM, memory on the GPU
*[CVAT]: Computer Vision Annotation Tool
*[HUD]: Hard hat, high-visibility vest and other worn safety gear
*[NMS]: Non-Maximum Suppression, pruning duplicate boxes by overlap
*[AP]: Average Precision, the area under one class's precision-recall curve
*[DFL]: Distribution Focal Loss, regressing a box edge as a distribution over bins
*[CIoU]: Complete IoU, an IoU loss adding centre-distance and aspect-ratio penalties
*[TAL]: Task-Aligned Assigner, picks training positives by combined class and IoU score
*[FPN]: Feature Pyramid Network, fuses coarse semantics into fine feature maps
*[PAN]: Path Aggregation Network, adds a bottom-up path on top of an FPN
*[AMP]: Automatic Mixed Precision, running parts of the model in FP16
*[EMA]: Exponential Moving Average, a smoothed copy of the weights used for evaluation
*[MOTA]: Multi-Object Tracking Accuracy, combining misses, false positives and id switches
*[IDF1]: Identity F1, how consistently one identity maps to one object over its lifetime
*[HOTA]: Higher Order Tracking Accuracy, balancing detection against association quality
